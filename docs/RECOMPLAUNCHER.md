# RecompLauncher

The Windows release can include `TransformersArmada-v<VERSION>-Windows-x64.zip` for
[RecompLauncher](https://github.com/elripalda/RecompLauncher). It contains only `tfa-setup.exe`
and `recomplauncher.json`. The game is still built locally from the player's own USA disc,
SLUS-20668. There are no changes required in RecompLauncher.

Add this GitHub repository in RecompLauncher, install the Windows ZIP, then select your ISO in
Easy Setup. The setup runs without its own window, reports progress to the launcher and writes
`setup.log` in the installation folder. It uses the normal setup pipeline, including its existing
prerequisite installation. The first build takes about 15–25 minutes and needs about 15 GB free.
HD texture upscaling is skipped; sharp fonts and button prompts are generated by the normal setup.

`--prepare --iso <path> --folder <install>` is the headless setup entry point. A CI-built setup
uses its embedded `GITHUB_SHA` to check out the source belonging to that release. Local developer
builds without that variable use the project's default branch, like the normal installer.
Conflicting local source changes stop checkout; this mode does not force-checkout or commit them.

`--launch --iso <path> --folder <install> -- [game arguments]` starts the game without a setup
window. It rebuilds first if the executable is missing, setup was interrupted, or the release's
source revision differs from the successful build. Keep the ISO available for setup and repair.
The wrapper waits for the game and returns its exit code so RecompLauncher records the entire
session and backs up saves after the game closes. Closing a running headless setup terminates
the build's job object and its child processes.

The clone is under `<install>/transformers-armada-recomp`. Settings are in its `settings.ini`;
memory cards are `game/mc0` and `game/mc1`. The manifest exposes nine display, graphics and
controller settings, shared between the desktop and Big Picture views. A first Big Picture
launch defaults to full screen; a saved display choice wins. Native automatic update checks
are disabled for launcher starts, so RecompLauncher manages release selection.

Backups include the memory cards and `settings.ini`, excluding disc assets, generated code,
HD textures and save states. No whole-disc verification hash or verified-disc badge is claimed.
ReShade filters are disabled because this release starts through a setup wrapper. The integration
does not add BIOS or firmware management, and first-time setup requires Windows.

The managed setup does not create a separate desktop shortcut or replace the normal installer's
remembered installation folder. Starting `tfa-setup.exe` normally keeps its existing graphical
setup and standalone launch behavior.

To package an existing installer build without rebuilding it:

```powershell
.\installer\package_recomplauncher.ps1 -Exe .\installer\target\release\tfa-setup.exe
```

The existing release workflow tests the installer and uploads the generated ZIP beside the
standalone installer. It also runs when `recomplauncher.json` changes.
